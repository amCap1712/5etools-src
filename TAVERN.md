# The Tavern

An optional play layer for this 5etools fork: accounts (password + Google),
profiles, characters, and adventures with a full play-by-play chronicle.

- **Pages:** [`account.html`](account.html) · [`mycharacters.html`](mycharacters.html) · [`campaigns.html`](campaigns.html)
- **Backend:** [`server/`](server/README.md) (Flask + Postgres)
- **Frontend:** [`js/tavern/`](js/tavern/), themed by [`css/tavern.css`](css/tavern.css)

All of it is additive — no upstream files or data JSONs are modified, so
merges from upstream remain clean. See [`server/README.md`](server/README.md)
for setup and the roadmap.
